Settings & Saving

Where your plants are stored

Everything lives in data/plants.json in this GitHub repository. Your browser keeps a working copy so the site stays fast and works offline — press Publish to write your changes back to GitHub, which is also what the daily text message reads.

GitHub publishing

A fine-grained personal access token with Contents: Read and write on just this repository. It is stored only in this browser (localStorage) and is sent straight to github.com — nothing else ever sees it. Create a token →

Garden settings

Daily text message

A GitHub Action runs every morning, reads data/plants.json, and texts you the plants due that day with their watering instructions. No server, no cron machine — it runs on GitHub's free scheduled workflows.

Set it up once by adding repository secrets — see the setup steps in the README. You can also run it on demand from the repository's Actions tab.
